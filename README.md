# POOJA TOUR & TRAVELLS

Production-ready frontend foundation for the POOJA TOUR & TRAVELLS website, built with Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui, and Lucide icons.

## Development commands

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
npm run start
```

## Project structure

```text
public/images/          Static travel and brand assets
src/app/                App Router pages, metadata, and global styles
src/components/layout/  Reusable page-layout primitives
src/components/ui/      Reusable shadcn/ui components
src/components/forms/   Reusable form compositions
src/data/               Typed package and site data
src/lib/                Shared utilities
src/types/              Shared TypeScript domain types
```

## Brand colors

| Token | Hex | Purpose |
| --- | --- | --- |
| Primary navy | `#1a365d` | Brand identity, headings, primary actions |
| Accent gold | `#c9983c` | Highlights and selected accents |
| Background | `#f6fafd` | Main page background |

Lighter and darker derivatives are defined as reusable CSS variables in `src/app/globals.css`.

## Pre-launch content review

The privacy policy, terms, and cancellation policy are structured draft content, not finalized legal advice. Before launch, the agency owner and an appropriate legal or business adviser must confirm:

- Legal business identity, address, registration or tax details, and official contact information.
- Phone, WhatsApp, email, office location, operating hours, and social profile URLs.
- Payment methods, deposit and balance rules, quotation validity, and booking-confirmation workflow.
- Cancellation charges, amendment fees, refund timelines, supplier-specific rules, and exceptional-circumstance handling.
- Privacy contacts, service providers, analytics or marketing tools, and enquiry-data retention periods.
- Verified customer testimonials, approvals to publish them, and any licensed agency or team photography.
